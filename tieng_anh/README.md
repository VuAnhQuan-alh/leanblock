## Cách dùng

- Mở file `.pdf` trên iPad (GoodNotes / Notability / Files) rồi viết tay bằng Apple Pencil.
- **Làm xong phải nói to đáp án ra miệng** — không chỉ viết.
- Trang cuối mỗi tuần là đáp án; chỉ mở sau khi tự làm.

## Tạo lại PDF từ HTML

```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="tuan-01.pdf" "file://$PWD/tuan-01.html"
```
